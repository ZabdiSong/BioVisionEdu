## 选定的界面基线

主基线为 `Platform Demo/BioVision/index_1.html` 和同目录的 `style.css`、`script.js`，参考 `BioVision Edu UI design 1.0(1).pdf`。这些文件的副本在 `reference-design/` 中；该目录仅为设计参考，原型内的外部地址和示例数据不是正式网站运行依赖。

保留深蓝/青绿配色、左侧课程目录、Home / Study / Gallery / Exam / Forum / MyBio 六个入口、五问、步骤、资源和笔记的安排。重新实现真实课程和本地交互；没有把原型里的人名、示例学习记录、假题库规模或远程占位图用作真实内容。

## 课程范围与核对重点

完整实现 Unit 2 · The Cell 的 Cellular Energetics，第 9、10 章，共 16 个概念。手写设计中的 ETC 是详细示范，因此对应部分配了四步讲解、已有短片与专门模型。

课程文字和 48 道选择题为本次编写，不复制上传截图中的商业题库。核对重点包括糖酵解净产物、丙酮酸氧化/循环账目、复合体 II 不泵质子、氧受体、线粒体与叶绿体质子侧、Calvin 三碳产物、C4/CAM 空间/时间分隔，以及实验推论的限制。

## 公开上传包的边界

完整源码、数据、可用项目素材、模型、设计参考和说明均在包内。完整版权教材、私人访谈原文、大量重复版本及未确定用途的媒体保留在原上传材料中，没有重新分发到网页运行目录。清单可用来定位这些原件。

本次模型是用于解释区室和组件的教育示意，不替代真实分子结构。未创建新动画、未发布网站、未创建 GitHub 仓库或虚构仓库链接。
