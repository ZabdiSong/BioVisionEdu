# BIOVISION EDU 本地学习网站

这是按你上传的 HTML、UI 图、手写课程设计与访谈反馈完成的**细胞能量单元**：Unit 2 · The Cell，第 9、10 章细胞呼吸与光合作用。

**先解压整个文件夹，再双击 `index.html`。不要把 HTML 单独拖到其他位置。** 所有运行资源都在文件夹中，不需要安装依赖或连接外部服务。

## 已完成

- 16 个概念：五问讲解、完整文字解释、分步骤学习、易错点及输入输出表。
- 48 道原创题：解析、概念跳转、范围/难度/数量/时间设置、自适应练习。
- 可交互 3D：旋转、缩放、选结构、透明外膜、剖切、隔离选中部分。
- 4 个真正可编辑的 Blender 文件和 4 个 GLB 文件，已放入 `assets/models/`。
- 两个流程排序活动、关键词释义、搜索、笔记、标签、收藏、错题及进度备份。
- 已上传的 ETC 短视频和项目角色图。

## 按你的要求保留的空位

没有提供的课程图片保留空位；未完成的拟人动画与完整讲解视频显示“未完成”。没有制作新动画。Forum 是本机讨论草稿；共享论坛、教师课堂和账号功能标为未来版本。不会把模板里的虚拟人数或假学习记录作为真实数据。

学习记录保存在当前浏览器。更换设备或发布网站后，在 MyBio 导出/导入备份即可迁移；浏览器可能分别保存 `file://` 与网站地址下的记录。

## 上传 GitHub

解压后将 **index.html 所在文件夹内的全部内容**上传到仓库根目录。`assets`、`data`、`vendor` 都必须一起上传。不要仅上传压缩包，也不要只上传 HTML。

具体操作见 [GitHub 上传说明](docs/GITHUB_UPLOAD_CN.md)。已准备源码与 Pages 兼容路径，没有代你创建仓库或公开发布。
